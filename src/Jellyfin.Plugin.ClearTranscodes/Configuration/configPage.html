Files in the transcode temp directory older than this will be deleted when the "Clear Transcode Directory" scheduled task runs.
Comma-separated allow-list. A file is only ever deleted when its extension appears here — everything else is left alone, no matter how old it is. Leave empty to delete nothing at all.
Hidden files (such as Jellyfin's own .jellyfin-transcode marker) are always kept.
Only tick this if you have changed the transcoding path and are certain the folder contains nothing but scratch files. The task normally refuses to run unless the transcode path is Jellyfin's own default, because a custom path could point at a directory that holds something worth keeping — and video and subtitle extensions are on the delete list. The path in use is written to the server log on every run.
